# Health_Heaven


## Health Heaven — AI Ingredients & Health Query Chatbot

Health Heaven is a lightweight AI-powered chatbot that helps users understand the health impact of everyday ingredients.
Users can ask questions like:

“How much sugar is safe for a 10-year-old?”

“Is sodium good or bad for adults?”

“How much protein do teenagers need daily?”

The chatbot provides clear, age-appropriate, and science-backed answers about ingredients, daily limits, benefits, risks, and healthy alternatives.

## Features

🧠 AI-generated health explanations

🍽 Ingredient safety guidance (sugar, salt, fat, etc.)

👶 Age-based recommended intake

⚕ Warnings for excess consumption

🟢 Simple chat interface

☁ Can be integrated into any website/app

## Purpose

To help people make informed, healthier daily food choices with quick, reliable ingredient insights.
